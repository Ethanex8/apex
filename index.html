Preface ​

Apex unifies digital logic, printed-circuit electromagnetics, compiler construction, power electronics, and dynamic control around a single cohesive machine: an indoor-safe (about 2.5 kg, under 22 V) autonomous quadruped built without throwaway prototypes. Across eight chronological parts, we design a custom 32-bit processor implementing the open-standard Reduced Instruction Set Computer, Fifth Generation (RISC-V) architecture and deploy it onto a reprogrammable logic chip (Field-Programmable Gate Array, or FPGA). We then route a 6-layer controlled-impedance circuit board, write a C compiler and a deterministic task scheduler (Real-Time Operating System, or RTOS), build 20 kHz brushless motor drives and solid-state battery protection, and close whole-body locomotion and stereo navigation loops.

Every chapter develops one primary engineering discipline—combining plain-language intuition, interactive schematics, concrete numbers, concise math, verified source code in systems/, and closing hardware bench labs—growing section by section as each implementation step lands.

Start Reading ​

The prologue establishes the locked electrical, mechanical, and communication contracts shared across all six subsystems, and Chapter 1 begins Part I by constructing the software golden reference processor. Every chapter pairs words, visuals, concrete numbers, concise math, and live-synced code excerpts designed to be read sequentially:

  • Prologue — System Architecture and Contracts — How the six physical subsystems bolt directly into the final quadruped without circuit-board redesigns or throwaway bench builds.
  • Chapter 1 — Instruction Set Architecture — Software golden reference modeling, fixed-width modular binary arithmetic and two's complement, 32-bit instruction encoding, memory-mapped device registers, and fault or interrupt redirects (traps).

Complete Syllabus ​

The thirty-four chapters below follow the exact dependency order of roadmap.yaml, progressing from digital logic gates and board physics through actuators, power electronics, single-leg dynamics, quadruped walking, and stereo vision. Each part builds one major engineering layer and links directly to its subsystem reference contract.

Part I — Digital Logic and Processor Architecture ​

Part I constructs the custom 32-bit brain processor from fixed-width binary arithmetic up to a 5-stage pipelined hardware design accelerated by a custom two-lane 16-bit Multiply-Accumulate (mac) instruction. Every combinational circuit, register file, arithmetic unit, and trap path is verified instruction-for-instruction against a software reference model and timing-closed on reprogrammable FPGA fabric (brain Reference).
